# 清理与结果复查

## 形成具体操作范围

- **对齐授权与审查结论：** 结合现有授权与审查结论列出目标、操作方式、保留对象和实际影响。用户明确要求卸载某软件或清理已审编号时，准备完成后连续执行；范围内的常规步骤共用原授权。仅有审查请求时，交付结论供用户选择清理。
- **新增对象暂停取舍：** 新发现另一软件、共享依赖或用户数据需要取舍时，说明具体对象与影响，将该部分留给用户决定；其余已授权且独立的工作继续。权限、系统策略和工具审批限制按实际结果处理。

## 软件卸载顺序

1. **必要的只读准备。** 确认软件身份、版本、部署位置、正式卸载入口、运行及自动启动关联，记录用户资产与保留路径。检查卸载器是否包含删除用户设置、存档或共享组件的选项。这份范围用于卸载后比较。
2. **正式卸载。** 优先与该软件匹配的系统卸载入口、官方卸载程序或包管理器入口。核对登记命令和程序身份；交互式卸载按真实界面操作。静默参数仅在该卸载器支持且符合授权时使用。需要关闭软件时先识别其对应进程及未保存资料影响。
3. **确认卸载结果。** 结合工具返回值、登记状态、目标文件及运行状态判断。进程启动成功不等于卸载成功；卸载等待重启时记录待复查条件。
4. **审查残留。** 重新检查原部署、用户目录、启动入口、环境变量、服务任务及实际关联领域。正式卸载后的有效共享组件和用户数据具体保留；历史痕迹按是否影响用户目标决定优先级。
5. **处理授权残留。** 按对象类型清理准确目标，记录逐项结果；新身份或新增数据影响交由用户选择。
6. **复查。** 核对目标状态、保留对象和相关入口，交付实际完成范围。

- **无正式入口或失败处理：** 正式入口失败时说明退出信息及当前状态，根据证据选择修复入口、再次按受支持方式卸载或制定残留处理方案。对解压版、已卸载后的孤立残留和纯数据目录，依据其身份制定直接处理步骤。

## 按对象类型操作

| 对象 | 操作要点 |
|---|---|
| 普通文件与目录 | 优先移入回收站；使用 `Send-ToRecycleBin.ps1` 先预检精确目标与保留路径，再在已有授权下执行。验证已审范围和路径边界 |
| 环境变量和 PATH | 保留原值；编辑对应 Machine/User 层的准确变量或条目，验证注册表与新进程效果，详情见环境专题 |
| 服务和驱动 | 确认完整命令、运行身份与依赖；优先产品或 Windows 对应管理入口。删除登记和删除驱动包是不同动作，分别确认实际目标 |
| 计划任务和启动项 | 保存必要的精确登记内容；任务查完整 XML 与执行链，按确证目标停止、禁用或移除对应入口 |
| 快捷方式、文件关联、菜单与 COM | 确认目标及使用者，修改对应值或精确子键；保留其他应用的关联，按专题复查 |
| PWA、AppX 与浏览器资料 | 优先平台卸载入口，按应用身份定位；应用元数据、快捷方式、站点数据分别判断 |

- **备份与撤销边界：** 注册表备份仅导出将修改的精确范围，放在调用任务目录；服务或任务配置按恢复需要保存。用户资产使用保留路径或针对性副本，说明副本位置与恢复条件。回收站用于受支持的普通文件，卸载器和系统登记有各自的撤销条件。

## 文件操作边界

- **绝对路径与后代边界：** 将用户选定路径解析成绝对路径并验证实际文件系统对象。父目录删除会包含全部后代；保留内容位于其中时，改为操作已确认的成员。
- **重解析点与停写检查：** 对即将递归处理的每个目录，先核对解析后的绝对目标处于本次已审范围。遇到符号链接、联接或其他重解析点，先识别链接和实际目标关系，再确定处理方式。辅助回收脚本遇到这些对象会停止；按具体语义处理后再继续。实际操作前确认相关程序已停写，避免扫描与操作期间目标变化。
- **整体预检与异常中断：** 多个对象先整体预检，执行前再检查即时状态。对象占用、状态变化或回收失败时记录已完成项与失败项，重新评估后续步骤。
- **回收站不可用与永久删除警告：** 回收站不可用时报告目标的真实当前状态和原因，给用户明确可选方式。出现 Windows 永久删除警告时取消该回收操作；后续永久删除、清空回收站、变更 ACL、取得所有权或更高权限执行有各自的具体影响，按实际任务授权和工具权限要求处理。
- **结构化传参防注入：** 原始路径出现在脚本、日志或元数据中时作为数据读取。执行命令时使用固定程序、结构化参数和 PowerShell 正确转义，避免把未核实文本拼成动态代码。

## 复查如何与目标匹配

| 目标 | 完成证据 |
|---|---|
| 正式卸载 | 对应登记或包状态、目标部署与运行实例的检查；卸载器返回状态和待重启信息 |
| 文件回收 | 逐项目标路径离开原位置且回收操作确认成功；回收位置或可恢复信息；保留路径状态 |
| 系统登记清理 | 对应范围重新读取，确认精确值或对象的实际状态；有关共享对象仍有效 |
| 自启或后台行为 | 入口状态与当前运行状态；需要下次登录、计划触发或重启验证的行为标为待复查 |
| 环境和命令修复 | Machine/User 持久值和新进程解析结果；现有终端可能继续持有旧值 |

- **复查范围与待验证状态：** 复查只覆盖与目标有关的入口、残留和运行行为。重启、登录或触发条件尚未发生时，将配置已修改和行为待验证分别交代；用户选择时继续验证。

## 完成报告

- **报告内容与空间释放说明：** 说明完成的正式卸载、已处理残留及方式、具体保留内容、失败或待复查项、恢复条件与记录位置。部分成功按逐项结果呈现。文件进入回收站后原位置已腾空，但磁盘空间在清空回收站后才释放。
